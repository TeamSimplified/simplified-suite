old\ — the game's files as the mod found them
=============================================

Put here, from the version of the game the mod was BUILT AGAINST:

  gamedatabases.2025.bin      (game_package\gamedatabases\ in the install)
  localisation\*.lng          (every language file, named as the game names them)

new\ next door wants the same two things from the version you are UPDATING TO.

Why both: a mod ships whole files, not a list of changes, so the only way to
tell what the modder changed from what the game update changed is to compare
against the version they started from. What differs from old\ is theirs and is
carried over; what doesn't is the game's and is left as the update left it.

When the game updates again, what is in new\ becomes what belongs here.

The shader archives are not kept here. Those hold the game's shaders and
nothing else until a mod adds to them, so a mod's own resources are the ones the
archive never had — no old copy needed. They are taken fresh from the install,
which the app finds through Settings.
