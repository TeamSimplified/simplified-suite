new\ — the game's files at the version you are updating to
==========================================================

Put here, from the CURRENT version of the game:

  gamedatabases.2025.bin      (game_package\gamedatabases\ in the install)
  localisation\*.lng          (every language file, named as the game names them)

old\ next door wants the same two things from the version the mod was built
against. See the note in there for why both are needed.

These are the files the updated mod is built on: everything the mod did not
change comes from here, which is how a game update survives being re-modded.
